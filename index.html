Featured build 01 / 03 · TAMUHack 2026

        
Luma-Fume

        
An autonomous soldering assistant. A camera finds the soldering iron tip, then a light arm and a fume-fan arm turn to follow it.

        
Best 3D Model Design winner, TAMUHack 2026

        
  • NVIDIA Jetson Nano
  • YOLO + Roboflow
  • TensorRT
  • Python
  • OpenCV
  • PCA9685 over I²C
  • Servos

      

      
    


    

      

        
    
          
  1. 01 · What we were building
    Soldering takes more hands than you have, plus good light and somewhere for the fumes to go. We built a bench helper with two arms: one aims a light and one aims a fume fan at the iron tip, wherever it moves.
    2. 
          
  2. 02 · What I worked on My part
    I developed the computer-vision system on the Jetson Nano that tracks the iron tip, then wrote the servo-control code that maps each webcam observation to a target position and drives both arms through a PCA9685 servo controller.
    3. 
          
  3. 03 · What got better after testing
    Early runs were jittery. I calibrated every servo, added smoothing, a deadband, and a speed limit, and made the code ignore sudden jumps in the detection. Integrating TensorRT cut vision latency, and the arms moved visibly smoother.
    4. 
        

        
My favorite part was getting from camera detection to actual arm movement.Christin, on Luma-Fume

      

      

      
      

        
luma_fume.py · smoothing & safety config


# the values the arms run on now
ALPHA            = 0.08  # slow, steady output smoothing
INPUT_ALPHA      = 0.1   # smooth the detected tip position
DEADBAND         = 1.0   # ignore tiny changes
MAX_DEGREE_STEP  = 0.8   # speed limit per update
MAX_JUMP_LIMIT   = 250   # a big jump in the tip...
JUMP_PERSISTENCE = 5     # ...must last 5 frames

# each servo: 3-point calibration (0°, 90°, 180°)
ServoControl(channel=2, tick_0=560, tick_90=350, tick_180=150)

Featured build 02 / 03 · IEEE Technothon 2025

        
Gesture-Grip

        
Soldering helping hands you control with hand gestures. Pick a joint and move it without touching anything.

        
First Place, IEEE Technothon 2025

        
  • SolidWorks
  • Multi-joint arm design
  • Gesture sensing
  • Assembly
  • Iterative testing

      

      
    


    

      

        
    
          
  1. 01 · What we were building
    Helping hands you can reposition mid-solder without putting your tools down. You select a joint and adjust it with a touch-free hand gesture.
    2. 
          
  2. 02 · What I worked on My part
    I designed the multi-joint robotic arm assembly in SolidWorks, then led the physical assembly and testing of the build.
    3. 
          
  3. 03 · What got better after testing
    Testing the first version showed the arm was structurally unstable. I redesigned it over rounds of fixes and re-tests. Version 2 has a new frame and base, with the gesture sensors built into the front, and the arm holds steady.

Featured build 03 / 03 · TAMU Datathon

        
Luck or Leak

        
A dashboard that asks why a slot machine is earning less: bad luck, a bad location, or a payout leak.

        
Best Use of MongoDB, TAMU Datathon

        
  • Dashboard
  • Gemini API
  • MongoDB Atlas
  • Data analysis

      

      
    


    

      

        
    
          
  1. 01 · What we were building
    Casino managers tend to replace their lowest-earning machines. Our dashboard tests each one first: is it truly weak, or just unlucky, in a low-traffic spot, or paying out differently than its published game?
    2. 
          
  2. 02 · What I worked on My part
    I built the dashboard and integrated a Gemini chatbot. Before it answers, it pulls relevant context from MongoDB Atlas, and it logs each answer back to the database.
    3. 
          
  3. 03 · The result
    Our team won Best Use of MongoDB. The dashboard is live, so you can click through the real thing.
