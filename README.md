# christinchi.github.io

Personal portfolio of Christin Chi, computer engineering student at Texas A&M.

Live site: https://christinchi.github.io

Plain HTML, CSS, and JavaScript in a single `index.html`. Libraries load from CDNs:
[GSAP](https://github.com/greensock/gsap), [Lenis](https://github.com/darkroomengineering/lenis),
and [three.js](https://github.com/mrdoob/three.js) for the 3D Munchie Crane viewer.
